# Attention — 桌面悬浮番茄钟

基于 Python 的轻量级桌面番茄钟应用，无边框悬浮窗设计，始终置顶，专注不打扰。

## 功能特性

### 计时
- 开始 / 暂停 / 提前结束，三种状态自由切换
- 计时结束系统通知 + 提示音提醒
- 每次专注可填写可选的任务名称
- ±5 分钟微调，内置经典 25'、轻松 15'、深度 50' 三个预设
- 点击时间标签可直接输入自定义时长

### 界面
- 无边框悬浮窗，始终置顶，可自由拖拽
- 完整模式 + 迷你模式（100x52 像素），一键切换
- 深色 / 浅色主题一键切换
- 右下角可缩放窗口大小

### 其他
- 系统托盘支持，最小化到托盘不占任务栏
- 专注历史记录：记录任务名、起止时间、完成状态（自动完成 / 手动结束）

## 技术栈

| 依赖 | 用途 |
|------|------|
| customtkinter | UI 框架 |
| pystray | 系统托盘 |
| pillow | 托盘图标绘制 |
| plyer | 跨平台系统通知 |

## 项目结构

```
Attention/
├── main.py          # 主窗口与计时逻辑
├── config.py        # 配色方案、预设、窗口尺寸
├── dialogs.py       # 弹窗组件（开始专注、历史记录）
├── tray.py          # 系统托盘管理
└── requirements.txt # 依赖列表
```

## 运行

```bash
pip install -r requirements.txt
python main.py
```
